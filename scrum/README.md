# Scrum

Team process documents for Blue Baboons.

## Layout

```text
scrum/
├── README.md                          # This file
├── team-agreement.md                  # Team Agreement V1
├── templates/
│   └── scrum-meeting-template.md      # Copy this for every meeting
└── meetings/
    └── YYYY-MM-DD-meeting-NN.md       # One file per meeting
```

## Writing meeting notes

1. Copy `templates/scrum-meeting-template.md` to `meetings/YYYY-MM-DD-meeting-NN.md`, where `NN` is the next two-digit meeting number.
2. Fill in every section. If a section has nothing in it, write "None" instead of deleting it so all notes keep the same shape.
3. Link issues and PRs as `#NN`, and put every action item in the table with an owner and a due date.
4. Add the meeting to the log below in the same PR.
