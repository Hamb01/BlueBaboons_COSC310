## Discussion

### Rough user story ideas

- As a user, I want to be able to see all available restaurants so that I can choose the one I like.
- As a user, I want to be able to see specific details for each restaurant, such as their hours, menus and location.
- As a user, I want advanced search features to make finding restaurants I'd like easy.
- As a user, I want to see if a restaurant has a special deal going on to save money.
- As an admin, I want to be able to create restaurants and edit their details as needed.
- As a customer, I want to view the details of a specific restaurant so that I can decide whether to order from it.
- As a restaurant owner, I want to be able to add and update menu items and prices.
- As a customer, I want to search for specific restaurant cuisines.
- As an admin, I want to moderate users and edit who is allowed on the website.
- As a user, I want to see if I have missing information.
- As a user, I want to edit my JSON if I made mistakes.
